# Browser E2E Test Configuration

This directory contains browser automation tests using Playwright.

## Setup

```bash
npm install
npx playwright install chromium
```

## Running Tests

### All Tests
```bash
npm test
```

### Deterministic Workflow Tests (Issue #12)
```bash
npm run test:deterministic
```

### Headed Mode (for debugging)
```bash
npm run test:headed
```

### UI Mode
```bash
npm run test:ui
```

## Test Files

- `fixtures.spec.js` - Tests against the deterministic fixture site
- `deterministic.spec.js` - Comprehensive deterministic workflow tests (Issue #12)
- `api.spec.js` - Tests against the Hexactra API (when available)

## Fixture Site

The fixture site is generated by `scripts/create-fixture-site.sh` and provides:

- Navigation between pages
- Form inputs (text, email, password, checkboxes)
- Tabbed content
- Nested iframes
- OTP verification
- Approval flows
- Delayed actions
- Conditional visibility

## Deterministic Workflow Tests (Issue #12)

The `deterministic.spec.js` file contains comprehensive tests that verify:

### Test Categories

1. **Basic Navigation Flow**
   - Page loads correctly
   - Navigation between pages is deterministic
   - Elements are found by stable selectors

2. **Form Interactions**
   - Text inputs can be filled and verified
   - Checkboxes can be checked/unchecked
   - Form submission works reliably

3. **Tab Management**
   - Tab switching is deterministic
   - State persists across tab changes
   - Navigation history works correctly

4. **Frame Interaction**
   - Nested iframes are accessible
   - Elements in frames can be interacted with
   - Frame content is isolated properly

5. **Challenge Handling**
   - OTP verification accepts valid inputs
   - Delayed actions complete within expected time
   - Conditional visibility toggles correctly

6. **Recovery Scenarios**
   - Page refresh doesn't break navigation
   - Navigation history works correctly
   - Missing elements are handled gracefully

7. **Action Instrumentation**
   - Element states can be captured deterministically
   - Stable selectors work correctly
   - Interactions complete quickly

8. **Error Handling**
   - Missing elements are detected
   - Form validation works correctly

9. **Performance**
   - Page loads within expected time
   - Interactions complete quickly

### Running Tests with Fixture Server

The fixture server must be running for tests to work:

```bash
# Terminal 1: Start fixture server
cd fixtures
python3 -m http.server 8000

# Terminal 2: Run tests
npm run test:deterministic
```

Or use the combined script:

```bash
./scripts/run-deterministic-tests.sh all
```

## CI Integration

The tests run as part of the CI pipeline in `.github/workflows/ci.yml`.

## Determinism Guarantees

The fixture site provides these determinism guarantees:

- **Stable selectors**: Elements have predictable IDs and classes
- **Consistent state**: No random elements or changing content
- **Predictable timing**: Actions complete within known time bounds
- **Reproducible results**: Same inputs produce same outputs

## Integration with Chrome Extension

The fixture site is designed to work with the Hexactra Chrome extension:

1. Load the fixture site in Chrome
2. Open the extension's Side Panel
3. Use the extension to:
   - Observe DOM elements (semantic snapshots)
   - Click elements by selector
   - Type into form fields
   - Take screenshots
   - Switch between tabs

## Troubleshooting

### Tests fail with connection refused
Make sure the fixture server is running:
```bash
cd fixtures
python3 -m http.server 8000
```

### Tests fail to find elements
Check that the fixture site is loading correctly by opening `http://localhost:8000` in a browser.

### Playwright browser not found
Install Chromium:
```bash
npx playwright install chromium
```
